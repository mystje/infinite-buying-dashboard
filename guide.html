🤖 시스템 사용법

이 봇은 한국투자증권 OpenAPI로 미국 주식을 자동매매합니다. GitHub Actions에서 무인 실행되므로 PC를 켜둘 필요가 없습니다.

하루 일과 (미국 장 기준, 자동)

시각 (뉴욕)하는 일
폐장 100~5분 전종목별 매수·매도 주문 제출 (LOC/MOC/지정가) → 텔레그램으로 주문 목록 발송
폐장 30분 후체결내역·잔고 확인 → 상태(T값·V값·평단·잔금) 갱신 → 이 대시보드 갱신 → 텔레그램 정산 리포트

서머타임·조기폐장·휴장일은 자동 처리됩니다. 미체결 주문은 당일(DAY) 주문이라 자동 소멸합니다.

페이지 구성

  • 현황 — 종목별 진행 상태, 수익률 그래프, 사이클 이력
  • 설정 — 모든 전략 수치 편집·저장, 종목 추가/삭제, 수동 실행, 백테스트 실행 (GitHub 토큰 필요)
  • 백테스트 — 과거 데이터 시뮬레이션 결과 (최근 10회)

자주 하는 조작

하고 싶은 것방법
시드 변경설정 페이지에서 종목의 시드 수정 → 저장. 새 사이클(보유 0주)이면 즉시, 진행 중이면 다음 사이클부터 반영
종목 추가설정 페이지 하단에서 티커·거래소 입력 → 추가 → 시드·전략 설정 → 저장
자동매매 일시 중지설정 페이지에서 DRY RUN 켜기(전체) 또는 종목의 "사용" 해제(개별) → 저장
계좌 분리종목의 "계좌"를 VR 계좌로 선택 (GitHub Secrets에 KIS_ACCOUNT_NO_VR 필요)
지금 바로 실행설정 페이지의 "▶ 지금 주문 실행" / "🧾 지금 정산 실행" 버튼
⚠️ DRY RUN이 꺼져 있으면 실제 주문이 나갑니다. 오류·체결·정산은 모두 텔레그램으로 통보되며, 이상한 주문이 보이면 즉시 설정 페이지에서 DRY RUN을 켜세요 (당일 이미 제출된 주문은 한투 앱에서 취소).

♾️ 무한매수법 v4.0 (단기 사이클)

라오어의 무한매수법은 SOXL·TQQQ 같은 3배 레버리지 ETF를 매일 기계적으로 분할 매수해 평단을 낮추고, 목표가(별지점) 도달 시 익절하고 사이클을 새로 시작하는 전략입니다. 판단이 개입할 여지를 없애는 것이 핵심입니다.

핵심 용어

용어의미
분할수시드를 몇 번에 나눠 살지 (기본 40). 낮을수록 공격적
T값진행률. 1회분 매수 체결 +1 (절반 체결 +0.5), 쿼터매도 체결 시 ×0.75
1회매수금잔금 ÷ (분할수 − T) — 매일 재계산
별%base − coef×T (SOXL 40분할: 20−T / TQQQ: 15−0.75T). T가 커지면 목표가가 내려옴
별지점평단 × (1 + 별%) — 매도 목표가이자 매수 기준가
LOC 주문종가가 지정가보다 유리할 때만 종가로 체결되는 주문 (조건부 자동 실행의 핵심)

매일의 규칙

  1. 첫 매수 (T=0): 전일종가 +15% 가격에 LOC → 사실상 종가로 1회분 매수
  2. 전반전 (T < 분할수/2): 1회매수금의 절반을 LOC @별지점−0.01, 절반을 LOC @평단
  3. 후반전 (분할수/2 ≤ T): 1회매수금 전체를 LOC @별지점−0.01 (이때 별지점은 보통 평단 아래)
  4. 매도 (매일 걸어둠): 보유량 1/4을 LOC @별지점 (쿼터매도) + 나머지 3/4을 지정가 @별지점×(1+15~20%)

사이클의 끝

  • 전량 매도 성공 → 수익 확정, T=0으로 리셋하고 다음 날 새 사이클 자동 시작
  • 시드 소진 (T ≥ 분할수−1) → 아래 리버스모드로 자동 전환

🔄 리버스모드 (시드 소진 시)

시드를 다 썼는데 주가가 계속 낮으면, 손절 대신 등비수열 매도/매수로 버티며 회복을 기다리는 모드입니다. 감정 개입 없이 절차대로만 움직입니다.

  • 별지점(리버스): 평단이 아니라 직전 5거래일 종가 평균
  • 첫날: 보유량의 1/20을 MOC(종가) 매도 — 무조건 실행
  • 이후 매일: 보유량의 1/20을 LOC @별지점 매도 (별지점 위에서만 체결) + 잔금의 1/4을 LOC @별지점 아래 매수
  • T값: 매도 체결 시 ×0.95, 매수 체결 시 +남은분할×0.25
  • 복귀: 종가가 평단×(1−15%) (TQQQ) / ×(1−20%) (SOXL) 위로 올라오면 T를 승계한 채 일반모드로 복귀

매도/매수 모두 등비수열이라 보유량이 0이 되지 않습니다 ("무한"의 의미). 리버스 진입·복귀 시 텔레그램 알림이 옵니다.

📐 밸류 리밸런싱 — VR 5.0 (장기)

무한매수법이 짧은 사이클을 반복하는 단기 전략이라면, VR은 수년 단위 장기 투자 전략입니다. 평가금이 지향해야 할 기준선 V값을 정하고, 평가금이 밴드를 벗어날 때만 V로 되돌리는 매매를 합니다. 기준이 평단(과거)이 아니라 V 공식(미래 목표)인 것이 무한매수법과의 근본적 차이입니다.

핵심 용어와 공식

용어의미
V값평가금의 기준선. 시작 시 첫 매수 평가금으로 초기화
Pool (P)아직 투입하지 않은 현금
G값V 상승 속도의 분모. 클수록 보수적 (/10 → /20). 1년 단위로 점진 안정화 권장
밴드V × (1 ± 15%) — 이 안에 있으면 아무것도 안 함
다음 V = 현재 V + Pool/G + 적립금 (적립식) − 인출금 (인출식) — 2주마다

현금이 많을수록 목표선이 빨리 올라갑니다(P/G 항). 매도로 Pool이 커지면 상승 기울기↑, 매수로 Pool을 쓰면 기울기↓ — 자동 속도 조절.

2주 사이클 규칙

  1. 리밸런싱 데이: 적립/인출 반영 → V 갱신 → 밴드·Pool 한도 재설정
  2. 평가금 > 상단(1.15V): 초과분 매도 — 목적지는 밴드 경계가 아니라 V. 매도금은 Pool로
  3. 평가금 < 하단(0.85V): V까지 매수 — 단, Pool 사용 한도 내에서만
  4. 밴드 안: 거래 없음

유형별 차이

유형자금 흐름사이클당 Pool 사용 한도
적립식매 사이클 +적립금75%
거치식없음50%
인출식매 사이클 −인출금25%

이 봇의 자동화 방식

매일 상단/하단 트리거 가격에 LOC 주문을 걸어둡니다. 종가가 밴드를 벗어날 때만 자연 체결되므로 원문의 "2주치 예약주문"과 같은 효과이며, 체결 후에도 밴드 밖이면 다음 날 다시 주문되어 점진적으로 V에 수렴합니다.

❓ 자주 묻는 질문

주문이 "주문 없음"으로만 나와요

1회매수금(시드÷분할수)이 주가보다 작으면 1주도 살 수 없어 주문이 생략됩니다. 시드를 올리거나 분할수를 줄이세요. 대략 시드 ≥ 주가 × 분할수 × 2가 안전합니다.

주문이 거부됐다는 오류가 와요

대부분 계좌의 USD 예수금 부족입니다. 한투 앱에서 환전(또는 통합증거금 신청) 후 다음 실행을 기다리면 됩니다. 오류는 매일 텔레그램으로 통보됩니다.

같은 종목을 무한매수와 VR 둘 다 돌릴 수 있나요?

같은 계좌에서는 불가능합니다 (잔고가 티커 단위라 구분 불가). 계좌를 분리하면 가능합니다 (종목 설정의 "계좌" 선택).

봇이 멈춘 것 같아요

리포지토리의 Actions 탭에서 최근 실행을 확인하세요. GitHub는 60일간 커밋이 없으면 예약 실행을 중지하는데, 이 봇은 매일 정산을 커밋하므로 평소엔 해당되지 않습니다. 장기간 꺼뒀다 재개할 땐 Actions 탭에서 워크플로를 다시 활성화하세요.

KIS 앱키가 만료됐어요

앱키는 1년 유효입니다. KIS Developers에서 갱신 후 GitHub Secrets의 KIS_APP_KEY/KIS_APP_SECRET(및 _VR)만 교체하면 됩니다.

⚠️ 면책: 이 시스템과 문서는 투자 자문이 아닙니다. 전략 수치는 공개 자료 기반이며 원문과 다를 수 있습니다. 3배 레버리지 ETF는 하락장에서 −80% 수준의 손실도 가능하며 (백테스트 참고), 모든 투자 손익의 책임은 본인에게 있습니다.
