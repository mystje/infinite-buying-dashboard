GitHub 토큰

설정 저장에는 비공개 리포()에 쓸 수 있는 본인의 Fine-grained 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되며 GitHub API 외에는 어디에도 전송되지 않습니다.
권한: Contents Read and write (+ 실행 버튼을 쓰려면 Actions Read and write)

백테스트

현재 저장된 전략 설정으로 과거 데이터를 시뮬레이션합니다. 결과는 1~2분 후 백테스트 결과 페이지와 텔레그램으로 옵니다.

저장하면 비공개 리포의 config/settings.yaml에 커밋되고, 다음 실행부터 적용됩니다. 시드 변경은 새 사이클(보유 0주)이면 즉시, 진행 중이면 다음 사이클부터 반영됩니다.
